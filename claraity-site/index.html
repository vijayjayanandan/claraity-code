Multi-Layer Safety

The agent asks before it acts

An 8-layer safety system protects your code by default. Hard-blocked commands can never execute. Everything else requires your approval.

Command Hard-Block

Disk destruction, reverse shells, data exfiltration — permanently blocked

Approval Workflow

Edits, deletes, credential access — pause for confirmation

.claraityignore

Gitignore-style policy — blocked files can't be read, searched, or referenced

Diff Review + Undo

VS Code diff editor for every change — accept, reject, or undo any turn

Prompt Enrichment

Vague prompts in, precise instructions out

ClarAIty can rewrite your prompts before they reach the agent. Ambiguous references get resolved, missing context gets filled in, and you review the enriched version before sending.

  • Side-by-side preview — see original and enriched prompt, edit before sending
  • Context-aware — uses recent conversation history to resolve "this", "that", "continue"
  • Configurable model — use a fast/cheap model for enrichment, powerful model for the agent
  • Custom enrichment prompt — change how rewriting works via Settings
  • One-click toggle — sparkle icon to enable/disable per message

Extend It Your Way

Custom subagents and skills

8 built-in specialist agents. 7 built-in skills as slash commands. Create your own with a markdown file — no code changes required.

  • Code reviewer, test writer, doc writer, planner, knowledge builder, and more
  • Slash commands: /code-review, /safe-refactor, /test-driven-bugfix
  • Mix-and-match models — main agent on Claude Sonnet, reviewer on GPT-4o, explorer on Qwen (same endpoint)
  • Per-subagent tool restrictions and model overrides
  • MCP integration — connect databases, APIs, and external tools
  • Run up to 4 subagents in parallel

How it works
From install to productive in minutes

No complex setup. Install the extension, add your API key, and start coding with AI that you can actually watch think.

1

Install the extension

One click from the VS Code Marketplace. The agent binary is bundled — no Python installation required.

2

Add your API key

Paste your OpenAI or Anthropic key into settings. Keys are stored securely in VS Code SecretStorage -- never in files.

3

Open the sidebar

Click the ClarAIty icon in the activity bar. Type your first request and watch the agent get to work.

4

Stay in control

Review diffs before they land, approve sensitive operations, undo anything, and trace every decision.
